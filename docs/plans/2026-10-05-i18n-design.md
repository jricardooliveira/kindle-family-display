# Three-language display support

Support Portuguese, English and German equally for built-in UI, dates, weather, alerts, daily facts and synthetic demos. Locale, country and timezone are independent validated settings. Existing settings remain Portuguese for compatibility. Calendar headlines, RSS stories, names and photo captions remain in their source language.

Use small checked-in catalogs rather than an external translation runtime. Keep deterministic alert rules and raster rendering. A country-neutral `national` RSS category labels news for PT, GB or DE while retaining the legacy Portugal category. Germany, UK and Portugal receive no-key live presets and short native-language setup guides. Demo mode continues to work without network. Language/country changes invalidate display/weather/AI text caches as appropriate.

Tests require full catalog-key and placeholder parity, validated configuration, all-screen rendering in all languages including German overflow, country-specific news labels, weather code icon invariance, cache refresh/isolation and live app-compatible RSS feeds.
