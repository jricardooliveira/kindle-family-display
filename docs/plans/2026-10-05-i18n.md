# Equal Portuguese, English and German support

**Goal:** A new user can run a localized demo or live news/weather display in any of Portuguese, English and German without accounts.

**Approved design:** Lightweight translation catalogs cover all built-in screen text, dates, weather, alerts, facts and synthetic demos. Language (`pt`, `en`, `de`), country (`PT`, `GB`, `DE`) and timezone are independent settings. Preserve existing Portuguese configurations. Provide explicit country presets with RTP, BBC and Tagesschau respectively; German setup documentation makes cloning and starting straightforward. External calendar titles, headlines and photo names retain their source language.

**Architecture:** Keep Pillow, deterministic alert precedence, cached PNGs and optional AI. Add language to display context and display cache identity; localized weather source snapshots must also account for language. News supports a country-neutral `national` category while retaining legacy `portugal`. AI scores use the configured country and caches distinguish country/language.

**Dependencies:** Existing T1–T7 rendering, settings and collection interfaces are implemented and accepted in TASKS.md. This work extends those interfaces; hardware validation is independent.

3. Data assignment: own collectors, `app/decision/facts.py`, `app/decision/news.py`, `app/i18n/data.py`, and new data localization tests. Localize generated weather/alert/fact text and support national news; preserve alert ordering and cache correctness. Write failing tests before implementation.
4. Coordinator: country-aware optional AI scoring and cache integration; equal PT/GB/DE example configs, German quick start and README updates. Verify official publisher RSS feeds through the app parser/fetcher.
5. Review spec compliance, then quality/security; run the complete pytest, ruff and mypy checks. Smoke-test each preset and visually inspect localized PNGs. Report exact validation and any environment limitations.

## Acceptance

- All three languages have complete catalogs with matching interpolation placeholders.
- No host OS locale dependency or global mutable language setting.
- Unsupported languages/countries fail validation; old configuration stays Portuguese.
- Live news/weather presets work without keys; offline demo works without network.
- Locale/country changes do not reuse incompatible display/AI caches.
- Calendar/news source content is never silently translated.
- Full configured tests, lint, formatting and types pass; no private configuration is changed.
